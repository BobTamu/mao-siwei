## 1. 结构（Structural）

### 类型

**方法论集**。表面上跨越哲学、军事、政治、经济、党建、文艺六个领域，但底层是同一套认识—决策—执行的操作系统，只是在不同领域反复实例化。

### 一句话主旨

**在力量处于绝对劣势、信息高度不完整、时间又极度紧迫的条件下，如何用"调查研究—矛盾分析—集中优势—动员组织"这套流程，把分散的弱资源逐步转化为可以累积的胜势。**

### 骨架（六条主干 + 一条建设期延伸）

**主干 1｜认识论：结论只能从事实里长出来**
从《反对本本主义》（1930，"没有调查，没有发言权"）到《实践论》（1937，"实践—认识—再实践"）到《改造我们的学习》（1941，"实事求是"的定义），构成一条完整的认识论流水线：先定义"什么叫知道"，再规定"怎么才算知道"。这是全部方法论的**地基**，其他五条主干都从这里派生。

**主干 2｜矛盾分析：把混沌局面切成可处理的几块**
《矛盾论》（1937）给出的是**切分算法**而非世界观口号：普遍性与特殊性、主要矛盾与次要矛盾、矛盾的主要方面与次要方面、同一性与斗争性、对抗性矛盾与非对抗性矛盾。《论十大关系》（1956）与《关于正确处理人民内部矛盾的问题》（1957）是同一算法在建设期的两次实跑。

**主干 3｜战略学：在总体劣势中制造局部优势**
《中国革命战争的战略问题》（1936）与《论持久战》（1938）确立四件事：战略持久 + 战役速决；战略防御中的战役进攻；集中优势兵力、各个歼灭敌人；你打你的、我打我的（不被对手的节奏牵走）。十大军事原则是这四条的作战化清单。

**主干 4｜组织与领导：让正确的判断真正被执行**
《关于领导方法的若干问题》（1943，"一般号召与个别指导相结合""从群众中来，到群众中去"）、《党委会的工作方法》（1949，十二条）、《关心群众生活，注意工作方法》（1934）。这一条主干解决的是**方法论落地问题**——没有它，前三条只是纸上正确。

**主干 5｜政策与策略：在多方博弈中扩大同盟、缩小对手**
《目前抗日统一战线中的策略问题》（1940，"发展进步势力、争取中间势力、孤立顽固势力"）、《论政策》（1940）、《关于情况的通报》（1948）。核心是**区分敌我友的精度**与**斗争的有理、有利、有节**。

**主干 6｜工作方法与文风：降低组织内部的信息损耗**
《反对党八股》（1942）、《反对自由主义》（1937）、《关于建立报告制度》（1948）。把"写不清楚"和"不请示不报告"当成组织疾病而非个人毛病来治。

**延伸主干 7｜建设期的资源与矛盾配置**
《论十大关系》《关于国家资本主义》《党在过渡时期的总路线》。同一套矛盾分析算法，用在非战争场景时的形态变化——也是这套方法最容易失真的地方（见批判节）。

### 论点之间的关系

**不是并列，是三层递进 + 一次跨场景迁移**：
- 第 1 层（认识论）规定"什么算事实"；
- 第 2 层（矛盾分析）规定"从事实里切出什么"；
- 第 3 层（战略 / 策略 / 组织 / 文风）规定"切出来之后怎么打、怎么让人跟着打"；
- 第 7 条是前六条在建设期的迁移实验，成败参半，是批判的主要素材。

### 作者要解决的核心问题

**一个长期处于弱势、且必须靠自己判断而非靠既有权威行事的组织，如何避免"拍脑袋—挫败—再拍脑袋"的循环。** 这是贯穿 63 年的同一个问题，只是对手从国民党换成日本、再换成建设期的经济规律。

## 2. 解释（Interpretive）

### 关键术语（作者本人的用法，与常识用法的差异）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 实事求是 | "实事"是客观存在的一切事物，"是"是它们的内部联系即规律性，"求"是研究 | 常识指"老实、不夸张"；作者指的是**一套取证与归纳的作业规范**，与态度无关 |
| 矛盾 | 事物内部对立面的统一与斗争，是事物发展的**动力**而非故障 | 常识把矛盾当"冲突、麻烦"；作者把它当**分析工具与资源**，找不出矛盾才是问题 |
| 主要矛盾 | 在复杂过程中起领导、决定作用的那个矛盾 | 常识理解为"最紧急的事"；作者强调的是**决定性**（解决它，其余随之松动），不等于紧急 |
| 调查 | 用开调查会、蹲点、典型解剖等方式取得第一手材料 | 常识指"查资料"；作者明确反对看二手材料与"道听途说"，要求**到现场、找当事人、自己记录** |
| 群众路线 | 从群众中来（集中分散意见）→ 到群众中去（化为群众行动）→ 再从群众中来 | 常识理解为"听民意"；作者指的是一套**意见加工与回流的闭环流程**，且强调"化"的过程需要说服与试验 |
| 集中优势兵力 | 在决定性的时间与地点，造成相对（而非绝对）优势 | 常识理解为"人多打人少"；作者强调**局部与相对**，全局劣势下也能在一点上形成优势 |
| 歼灭战 | 以俘获/消灭对方有生力量为目标，而非占地 | 常识把"打赢"等同于"占地方"；作者把**消灭对方能力**与**占领空间**严格区分，前者才是目的 |
| 持久战 | 在敌强我弱时，用时间换力量对比的反转 | 常识理解为"拖"；作者给出三阶段（战略防御—战略相持—战略反攻）与每阶段的不同任务，是**分阶段的主动设计** |
| 纸老虎 | 战略上藐视（长期看它弱）、战术上重视（当下它真能吃人） | 常识当作"轻敌口号"；作者的原意是**两个层面必须同时成立**，缺一半就变成冒险主义或右倾 |
| 一般号召与个别指导 | 先普遍部署，再抓一两个点突破，用突破后的经验去修正普遍部署 | 常识理解为"抓典型"；作者强调**回到一般**的那一步，只抓点不推广等于没做 |
| 九个指头与一个指头 | 判断事物性质看主要方面（九个指头），但不放过次要方面（一个指头） | 常被当作"掩盖问题"的话术；原始用法是**分主次的定量比喻**，前提是先承认那"一个指头"确实存在 |

### 核心命题（用自己的话）

1. **不知道就不能说**：没有调查就没有发言权；判断力来自一手材料，不来自权威或书本。
2. **先切分，再决策**：任何复杂局面都能切成主要矛盾与次要矛盾；决策失误多半是切错了层，而不是算错了数。
3. **劣势方唯一的胜法是制造局部优势**：全局无法取胜时，放弃平均用力，在一点上集中，各个击破。
4. **节奏权比资源权更关键**：被对手牵着走，资源再多也是消耗；"你打你的，我打我的"是把节奏权夺回来的具体做法。
5. **正确判断必须配一套落地机制**：一般号召 + 个别指导 + 检查 + 总结，四步缺一步，判断就停在纸上。
6. **同盟的边界决定胜负**：任何时候都要分清谁是当前的主要对手、谁是可以争取的中间力量；把中间力量推向对手是最常见的自伤。
7. **写不清楚是组织病**：党八股、不报告、不请示，都是信息在组织内损耗的具体形态，要当成工程问题治。

### 论证链

作者的论证路径不是学院式的"提出假设—检验"，而是**"复盘实战—抽出通则—下一次实战验证"**的循环：几乎每一篇重要文本都有明确的现实对手与具体战场（湘江、井冈山、长征、延安整风、三大战役、合作化）。这使得其方法论具有极强的可操作性，同时也埋下了一个结构性弱点：**通则的成立高度依赖"作者本人能持续做出正确判断"这一前提**（见批判节最强反对意见）。

## 3. 批判（Critical）★

> 以下批判直接成为下游能力卡 B（Boundary）字段的来源，也是"这套方法什么时候不该用"的判据来源。

### 作者的时代局限

- **战争与革命年代的范式烙印**：核心概念（敌我、歼灭、战线、动员）都从军事斗争里长出来。迁移到商业、科研、日常生活时，"敌我"这个最基础的划分会失真——多数真实场景没有敌人，只有利益不一致的合作者。
- **对群众运动效力的高估**：在信息稀缺、组织薄弱的年代，运动式动员是低成本高效率的手段；在需要长期专业积累的领域（科研、医疗、精密制造），运动式推进的边际收益迅速转负。
- **对计划经济与主观能动性的乐观**：建设期文本中，"人有多大胆、地有多大产"式的推论在方法论层面留下了未被清理的漏洞——把"能动员起来"误当成"能生产出来"。

### 作者的立场盲点

- **对制度化制衡的轻视**：强调"集中的党委领导"与"一元化"，对权力分工、程序约束、独立监督的系统性作用着墨很少。这是"党委会的工作方法"这类能力卡必须写的硬边界。
- **对专业分工的轻视**：在"外行领导内行"的框架下，专业判断常被当作立场问题处理。
- **幸存者偏差**：所有文本都是**成功之后写的复盘**，失败的决策过程（如某些战役初期的误判、大跃进期间的判断）很少以同等细致的方法论形态被复盘。用这套方法时必须意识到：样本只包含赢的那一半。

### 未被证明的假设

- 假设**矛盾可以被正确识别**，且识别者具备足够的信息与判断力。当信息严重不足或识别者本身是被考核对象时，"找主要矛盾"极易退化为"找对自己最有利的那个矛盾"。
- 假设**集中优势之后能迅速转化为战果**。在歼灭战里这成立（缴获即补给）；在商业/科研里，投入集中后可能长期无产出，转换链条远长于战争。
- 假设**群众意见经过"集中"能变成正确政策**。缺少对"集中"环节本身的质量控制（谁来集中、依据什么标准取舍），这一环是整套流程里最脆弱的一节。

### 最强反对意见

**"矛盾分析"在最需要它的时候最不可靠。** 它要求分析者在信息不完整时判断"哪个是主要矛盾"，但信息不完整恰恰是判断力最差的时刻；而事后复盘又会把已经发生的结果解释成"主要矛盾本来就该是那个"，使方法看起来永远正确、实际不可证伪。
配套的反驳还有两条：**"集中优势兵力"依赖组织强制力**——能集中是因为能命令，不是因为算得准；**"群众路线"在大规模组织中容易变成动员技术**——"从群众中来"的那一半被压缩，"到群众中去"的那一半被放大。

**这三条反对意见不是否定这套方法，而是给出它的适用边界：它是弱势方在硬约束下的生存方法论，不是普适的成功学。**

## 4. 应用潜力（Applicability）

### 可 skill 化的内容

- [ ] 矛盾切分：从混沌局面中找出主要矛盾与矛盾主要方面（含"切错了怎么办"的纠错回路）
- [ ] 调查研究：开调查会、典型解剖、蹲点取证的操作规范（含"调查什么、问谁、怎么记"）
- [ ] 持久战式资源规划：弱势方的分阶段设计与节奏权争夺
- [ ] 集中优势：在多点任务中选出决定性一点并放弃其余
- [ ] 群众路线闭环：意见收集—加工—试点—推广—再收集
- [ ] 一般号召与个别指导：抓点、突破、回到一般的四步法
- [ ] 党委会工作方法：十二条落到会议、汇报、决策、检查的机制设计
- [ ] 政策与策略：发展进步、争取中间、孤立顽固的三分法
- [ ] 反对党八股：把"写清楚"变成可检查的写作规范
- [ ] 纸老虎两层判断：战略藐视与战术重视的分离操作
- [ ] 两类矛盾区分：对抗性 / 非对抗性的判别与处置差异
- [ ] 报告制度：请示—报告—通报的信息流转设计
- [ ] 复盘与总结：从战役复盘中抽出通则的方法
- [ ] 统战式谈判：有理、有利、有节的三条边界

### 不适合 skill 化的内容

- 具体历史评价、人物臧否、路线斗争叙述 → 保留为案例与上下文，不独立成能力
- 诗词、文学性文本 → 只作背景语料
- 语录体摘句 → 只作检索入口，不作证据（脱离上下文后极易被误用）
- 读书笔记解析（二手研究）→ 引用时必须标注"二手"，不与方法论原文混用

### 预估 skill 数量

**约 20–26 个能力卡**（single 模式：1 个入口 + 内部能力卡路由）。最终由阶段 1.5 三重验证与阶段 1.6 晋级门决定。

### 优先级排序（按"最能赋能普通人"）

1. **矛盾切分** —— 通用性最强，任何决策场景都能用，且原文本密度最高（矛盾论 + 十大关系 + 两类矛盾）
2. **调查研究** —— 直接对症"凭印象决策"这一最常见失误
3. **一般号召与个别指导 + 群众路线闭环** —— 解决"想清楚了但落不下去"
4. **集中优势 + 节奏权** —— 资源永远不够时的分配算法
5. **党委会工作方法** —— 会议与汇报的机制化，最容易立即套用
6. **反对党八股** —— 写作与表达的检查清单
