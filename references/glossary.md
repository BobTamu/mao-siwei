# 术语表 — 毛泽东著作方法论（37 条）

> 收的是**作者有专有用法、且与常识有实质差异**的词。混用会直接导致判断错误，所以每条都标了误用风险。

| 术语 | 作者的用法 | 与常识的差异 / 误用风险 |
|---|---|---|
| 实事求是 | "实事"是客观存在的一切事物，"是"是内部联系即规律性，"求"是研究 | 常识指"老实不夸张"；作者指的是一套**取证与归纳的作业规范**，与态度无关 |
| 矛盾 | 事物内部对立面的统一与斗争，是发展的**动力** | 常识当"冲突、麻烦"；作者当**分析工具**——找不出矛盾才是问题 |
| 主要矛盾 | 在复杂过程中起领导、决定作用的那个矛盾 | 不等于"最紧急的事"（那是次要矛盾在闹）；判据是**决定性** |
| 矛盾的主要方面 | 矛盾双方中决定事物性质的那一侧 | 与"主要矛盾"常被混为一谈：一个指**哪一条**矛盾，一个指**哪一侧** |
| 同一性 | 矛盾双方在一定条件下互相依存、互相转化 | 不是"一致性"；离开条件谈转化即失效 |
| 对抗性 / 非对抗性矛盾 | 前者要剥夺对方行动能力，后者只是认识与分配之争 | 不是"激烈程度"之分，是**性质**之分，决定用强制还是说服 |
| 实践 | 人改造世界的活动，是认识的来源与检验标准 | 不等于"经验"；作者强调实践要能**证伪**结论 |
| 感性认识 / 理性认识 | 前者是零散印象，后者是概念与判断的系统 | 不是"深浅"之分，是**能否揭示内部联系**之分 |
| 调查研究 | 开调查会、蹲点、典型解剖，取得第一手材料 | 不等于"查资料"；反对看二手材料与道听途说 |
| 本本主义 | 把书本、上级指示当作免检的真理 | 不是"爱读书"，是**取消检验环节** |
| 主观主义 | 不问环境、不看全体就下判断 | 不等于"有主见"；病征是脱离具体条件 |
| 党八股 | 只有格式没有内容的文风（开中药铺） | 不是"文章难看"，是**用分类代替分析** |
| 自由主义 | 组织内部取消思想斗争、以和气代替原则 | 与政治哲学意义上的"自由主义"无关，混用会把整篇读反 |
| 命令主义 / 尾巴主义 | 前者强迫，后者跟着落后意见跑 | 是一对：都放弃了"从群众中来、到群众中去"的加工环节 |
| 群众路线 | 收集分散意见 → 加工成系统意见 → 回流为群众行动 → 行动中检验 | 不等于"听民意"；核心在被压缩的"集中"环节 |
| 一般号召 / 个别指导 | 普遍部署 + 抓两三个点突破 + 回填部署 | 抓点不做推广等于经验主义；只发号召等于官僚主义 |
| 一元化 | 一个地区内党政军群领导集中于一个领导机关 | 是特定历史条件下的组织安排，不是通用的"一把手负责制" |
| 党委制 | 集体讨论决定、分头负责执行的会议决策制度 | 与"集体领导"配套；缺个人负责就会无人担责 |
| 报告制度 | 固定周期、固定字段、主责人署名的书面汇报机制 | 不是"多汇报"，而是**用规格对抗失真** |
| 集中优势兵力 | 在决定性时间地点造成 3–6 倍**绝对**优势（原文："集中绝对优势的兵力，即集中六倍、或五倍、或四倍于敌的兵力"） | 不是"总体力量强"；写作"相对"会把标准降成"比对方略多"，正好落入"处处略强而处处不足"的误用。要求敢放弃其他方向 |
| 歼灭战 | 以消灭对方有生力量为目标，不以占地为目标 | 与"打赢"不等价：占地而未歼敌，作者判为白打 |
| 消耗战 | 以消耗对方为战略目的，但须以战役歼灭为手段 | 不是被动互耗；混用会变成拼家底 |
| 持久战 | 分三阶段（防御—相持—反攻）的主动设计 | 不是"拖"；每阶段任务不同 |
| 内线中的外线 | 战略上被包围，战役上包围对方 | 两层方向相反是设计，不是矛盾 |
| 游击战 | 分散流动的非正规作战，但有战略地位 | 不等于"打游击式的随意"；作者强调其战略配合作用 |
| 根据地 | 能自给、能练兵、能政权的稳定区域 | 不是"地盘"，是**能力积累的容器** |
| 统一战线 | 为共同目标与不同力量结成的联盟 | 不等于"团结"；内含斗争与独立自主 |
| 独立自主 | 合作中保留思想、政治、组织三条独立性 | 不是"不合作"；与统一战线必须同时成立 |
| 有理、有利、有节 | 自卫、必胜、适可而止三条边界 | 缺"有节"会把可合作者永久推向对立面 |
| 进步 / 中间 / 顽固势力 | 按与我方关系方向切的三段 | 不是道德评价；判断依据是**当前主要对手** |
| 两面性 | 同一阶级或力量同时具有革命性与妥协性 | 不是"表里不一"；指结构性的双重可能 |
| 纸老虎 | 长期本质层弱、当下具体层强 | 只取一层即失效：只取前者轻敌，只取后者不敢动 |
| 九个指头与一个指头 | 看性质看主要方面（九个），但不否认次要方面（一个） | 原始用法是**分主次的定量比喻**，前提是先承认那"一个"确实存在 |
| 人民内部矛盾 | 利益根本一致前提下的认识与分配分歧 | 与敌我矛盾相对；处置方式只能用讨论说服 |
| 惩前毖后，治病救人 | 揭发错误是为后来慎重，对象是病不是人 | 不是"从轻处理"，也不是"清算" |
| 波浪式推进 | 有起伏、有间歇、分批次的推进方式 | 不是"时紧时松"，节奏由条件成熟度决定 |
| 五风 | 共产风、浮夸风、命令风、干部特殊风、瞎指挥风 | 特定历史名词；作为**失真类型清单**仍有迁移价值 |

## B2 补充（《文集》八卷新增 20 条）

| 术语 | 作者的用法 | 与常识的差异 / 误用风险 |
|---|---|---|
| 分兵以发动群众，集中以应付敌人 | 平时分散做群众工作，遇敌时迅速集中作战 | 不是"分兵把守"；分散的目的是发动，不是防守 |
| 原耕总合分配 | 按原耕地为基础、抽多补少抽肥补瘦的分配法 | 不是"打乱重分"；抽补的前提是承认原耕基础 |
| 精兵简政 | 精简、统一、效能、节约、反官僚主义五项目标 | 不是"裁人省钱"；只看人数下降而不看效能，是精简失败 |
| 三三制 | 政权机构中共产党员占三分之一 | 不是"轮流坐庄"；核心是主动设上限换取长期合作 |
| 拥政爱民 / 拥军优抗 | 军队拥护政府、政府爱护军队的双向义务 | 不是单方面表态；是互相约束的制度安排 |
| 创造战场 | 主动选择并改造作战地域，把不利地形变成有利 | 不是"等好地形"；是主动造出来 |
| 平分土地 | 按人口平均分配土地的政策形态 | 与"原耕总合分配"是两种不同方案，不可混称 |
| 国家资本主义 | 国家与私人资本结合、受国家管理的形式 | 不是"国家办企业"；重点是结合方式与领导权 |
| 商品生产 | 社会主义条件下仍需保留的商品交换 | 与"资本主义"分开看：作者明确两者不等同 |
| 统筹兼顾、适当安排 | 各方面利益都要照顾，但按轻重缓急安排 | 不是"平均分配"；重点是安排而非均分 |
| 百花齐放、百家争鸣 | 艺术与学术领域的自由讨论方针 | 不等于无边界；作者同时强调政治标准 |
| 长期共存、互相监督 | 多党合作的基本方针 | 不是"合并"也不是"对立"；监督是相互的 |
| 小民主 | 日常的、小范围的、可操作的民主形式 | 与"大民主"（群众运动式）相对，作者倾向前者 |
| 少数人闹事 | 群众中少数人的集体行动 | 不是"敌人破坏"；多数起因于领导官僚主义 |
| 绞索 | 对手在自己制造的困境中被牵制 | 不是"威胁"；指结构性牵制关系 |
| 一平二调 | 平均分配、无偿调拨 | 特定错误做法，作者视其为破坏生产积极性的根源 |
| 五多五少 | 会议多、文件多、报表多……落实少 | 不是"形式主义"泛称；是五组可数的具体失衡 |
| 价值法则 | 价值规律，作者称其为"一个伟大的学校" | 不是"资本主义范畴"；作者认为它教人算账 |
| 两条腿走路 | 同时用两种办法推进（如中央与地方、大中小并举） | 不是"两手抓"泛称；指两条并行的实施路径 |
| 两个中间地带 | 国际格局中除两极之外的中间区域 | 不是"第三方"；指可争取的战略空间 |

## B3 补充（《军事文选》六卷新增 20 条）

| 术语 | 作者的用法 | 与常识的差异 / 误用风险 |
|---|---|---|
| 围城打援 | 以攻城为诱饵，主力打援军 | 不是"又攻城又打援"；攻城是手段，打援是目的 |
| 钳制 | 用少量兵力吸住对方一部，使其不能他去 | 不是"牵制性进攻"；钳制部队的任务是不输，不是赢 |
| 速决战 | 单次战役要求快打快歼，与战略持久相对 | 与"持久战"不矛盾：两层方向相反是设计 |
| 击溃战 | 打散对方但未歼灭，作者视其为无效战果 | 常识当"打赢"；无缴获即无补充，等于白打 |
| 有生力量 | 对方的人员与建制能力，而非土地与装备 | 不是"兵力数量"；重点是建制是否还在 |
| 诱敌深入 | 主动退让，把对方拉进对其不利的地域 | 不是"逃跑"；退是有预设战场与条件的 |
| 袭击 | 游击战的基本战术形态：秘密接近、突然解决 | 不是"偷袭"泛称；强调快打快撤与不吃亏 |
| 运动战 | 大踏步进退、在运动中歼敌的正规作战形式 | 不是"移动着打"；核心是制造对方的运动 |
| 战略决战 | 决定全局胜负的会战，须条件齐备才可举行 | 不是"大仗"；判断标准是"输了还能不能再来" |
| 宽待俘虏 | 不杀、不辱、给以教育后释放或留用 | 不是"仁慈"；是瓦解敌军的制度化手段 |
| 地方兵团 | 固定区域作战的地方武装，是主力的来源与根基 | 不是"杂牌"；抽空它等于断掉兵源 |
| 兵站线 | 沿交通线设置的补给节点与转运体系 | 不是"仓库"；重点在线的连续性 |
| 节节抗击 | 分段阻击、逐次消耗、边打边退 | 不是"溃退"；每一段都要有预设阵地与撤退条件 |
| 攻城与打援 | 攻坚时两套部署必须同时成立 | 只攻不打援，会被援军反包围 |
| 即俘即补 | 俘虏经简短甄别即补入部队 | 不是"抓丁"；有甄别程序与专门机构 |
| 军事民主 | 作战方法可在火线开会讨论，指挥权不下放 | 不是"投票决定打仗"；讨论限于方法 |
| 诉苦三查 | 诉苦（讲具体经历）+ 三查（查阶级、工作、斗志） | 不是"检讨会"；要求落到岗位与任务调整 |
| 蘑菇战术 | 用小部队与敌周旋，"磨"到对方疲惫再打 | 不是"拖延"；磨的过程要消耗对方并保存自己 |
| 轮番作战 | 多支部队交替投入、轮换休整 | 不是"添油"；关键是整建制轮换而非零散补人 |
| 关门打狗 | 先封闭退路，再就地歼灭 | 不是"瓮中捉鳖"式成语；前提是确实封住了门 |

## B5 补充（文稿 8-12 册新增 19 条）

| 术语 | 作者的用法 | 与常识的差异 / 误用风险 |
|---|---|---|
| 旧帐要算 | 公社化中平调社员的财物账目要清算 | 不是"翻旧账"贬义；作者明确把"旧帐一般不算"改为"一般要算" |
| 一风吹 | 一道命令全部解散或全部恢复 | 不是"一阵风"泛称；特指用行政命令一次性抹平的做法 |
| 供给制 | 按人平均分配生活资料的部分 | 与"共产风"不同：经社员同意与上级批准的供给制不算共产风 |
| 观潮派、算帐派 | 被指为观望和算细账的人 | 作者后期承认"有许多其实并不是"——标签本身常被误用 |
| 瞒产私分 | 生产单位隐瞒产量、私下分配 | 不是"贪污"；是上级指标脱离现实时的应对行为 |
| 主动权 | 判断与行动的自主余地，来自对实情的掌握 | 不是"权力"；作者说"主动权来自实事求是" |
| 三级所有、队为基础 | 公社、大队、生产队三级所有，以生产队为基本核算单位 | 不是"三级平均"；核心是核算单位落在哪一级 |
| 三包一奖 | 包工、包产、包成本，超产奖励 | 作者批评其条款过多（37 道工序、1128 笔账），视为烦琐哲学典型 |
| 公共食堂 | 以生产队或大队为单位的集体用饭制度 | 不是"食堂"通称；是分配制度的一环，撤销要防一风吹 |
| 留有余地 | 计划指标定在可达水平之下 | 不是"保守"；作者认为余地是抗风险的余量，不是留后手 |
| 鞍钢宪法 | 两参一改三结合的企业管理原则 | 不是"鞍钢的制度"；是一套管理原则的名称 |
| 半工半读 | 学习与劳动各占一定比例的教育形式 | 不是"勤工俭学"；有明确比例（如四比六）与课程削减 |
| 四清（四不清） | 清工分、清账目、清财物、清仓库等 | 1963 与 1965 两期含义不同，引用须标年份 |
| 单干（单干风） | 农户个体经营 | 在文本中是批判对象，但"包产到户"与之并非同义，不可混用 |
| 蹲点 | 干部长期驻在一个点上工作与调查 | 不是"视察"；要求住下来、参与劳动、待够时长 |
| 接班人 | 培养后续领导力量的提法 | 1964 年语境下的政治概念，不宜作通用管理术语挪用 |
| 和平演变 | 对社会主义国家施加非军事影响的判断 | 冷战语境术语，与"文化交流"不可混谈 |
| 备战、备荒、为人民 | 三线建设时期的总方针 | 不是"口号"；与三线布局、粮食储备、征购比例直接挂钩 |
| 八字宪法 | 农业增产的八项要素（土肥水种密保管工） | 引文出自注释，非正文；引用须标注出处层级 |

## 更正与补注（B5 术语提取提出）

1. **「五风」**需补判据：共产风＝无偿占有别人劳动成果；经全体社员同意和上级批准的某些统一分配办法（如粮食供给制）**不算**共产风。原条目只列五名，下游容易把供给制误判成共产风。
2. **「九个指头与一个指头」**补出处：1959.2.27 郑州讲话原句"我们的成绩和缺点的关系，正如我们所常说的，只是十个指头中九个指头和一个指头的关系"。
3. **年代警示**：`赤脚医生`在本书 8 次出现**全部在 1968 年 9 月**之后，1959–1965 年文本零出现，引用前十册不得使用该词。


## B6 补充（读政治经济学批注 + 思想万岁 第三、四卷，新增 15 条）

| 术语 | 作者的用法 | 与常识的差异 / 误用风险 |
|---|---|---|
| 大集体、小自由 | 集体经济为主、个人小自由为辅的制度安排 | 不是"管得松"；是明确的配比原则，小自由有边界 |
| 两本账 | 计划分必成数与争取数两本 | 不是"两套报表"；第二本是公开的努力目标 |
| 死级活评 | 级别固定、评工活分 | 不是"浮动工资"；级不动、分值动 |
| 全民所有制 | 生产资料归全体人民所有的形式 | 与"国有"在文本中常互换，但作者强调其内部仍有调拨关系 |
| 调拨 | 全民所有制内部按计划转移产品，不转移所有权 | 不是"调配"泛称；正因为不转移所有权，所以不是商品 |
| 以钢为纲 | 以钢铁为中心带动其他行业的比例安排 | 不是"只搞钢铁"；是指标体系里的牵头项 |
| 综合平衡 | 各主要比例同时平衡的编制方法 | 不是"平均"；指结构比例不出现缺口 |
| 物质刺激 | 以物质利益驱动劳动积极性的手段 | 在文本中是受限制对象，作者主张"为辅"而非取消 |
| 计件工资 | 按产量计酬 | 作者列为辅形式，理由是加剧新老、强弱、轻重三类矛盾 |
| 赢利 | 企业销售收入的剩余部分 | 不是"利润最大化"；在文本中指核算是否成立 |
| 无形损耗 | 设备因技术进步而贬值 | 不是"折旧"；是技术换代造成的价值损失 |
| 级差地租 | 因土地条件差异形成的超额收益 | 社会主义语境下仍承认其存在，与教科书说法不同 |
| 包产到户 | 以户为单位承包产量 | 1962 年按"到户比例"定性，且主张对已实行的不强纠 |
| 三结合 | 干部、技术人员、工人三方面结合 | 与"两参一改三结合"同源，但"三结合"另有两义（老中青），须看语境 |
| 全国一盘棋 | 全局统一安排、局部服从整体 | 不是"中央集权"；强调的是一致的方向而非一律的指令 |

## 更正（B6 提出，涉及 B5 条目）

1. **「单干（单干风）」**：B5 写"包产到户与之并非同义"，需改为——**按到户比例定性，组织上不强纠**。依据：1962.8.6 北戴河讲话按比例判"实质上叫大部分单干"，同篇又主张已包产到户的不要强迫纠正。
2. **「三级所有、队为基础」**：补出处与判据——1961.9.29 信"基本核算单位是队而不是大队"；1959 郑州会议的对应表述是"三级核算，各计盈亏"。两个提法不可混为同年同句。
3. **「五风」共产风**：补逐字清单——"一是穷富拉平，二是积累太多，义务劳动太多"，并附排除项"如粮食供给制等，这些都不属于无偿占有性质"。

## 使用说明
- 读到"矛盾"时先问：这里指**对立关系**还是**问题麻烦**？作者一律指前者。
- "主要矛盾"与"矛盾的主要方面"必须分开用，混用会让分析停在表层。
- "自由主义""消耗战""集中优势兵力"三个词与常识偏差最大，是误读高发区。
