# 决策规则速查 — 毛泽东著作方法论语料库（选集、文集、军事文选、文稿 1-13、政经批注、思想万岁、早期文稿）

| 能力 | 一句话规则 |
|---|---|
| 实践—认识—再实践闭环 | 把判断放回实践里跑一轮，用预测误差而不是说服力来校正结论 |
| 结论后置于调查 | 先取证再表态，没有一手调查就没有发言权 |
| 调查取证四条硬规矩 | 选人、规模、提纲、记录四条参数缺一，拿回的材料就是失真的 |
| 解剖麻雀与试点分批 | 取最坏样本解剖到底，再试点分批推开，不做一次性全面铺开 |
| 决策三道前置闸 | 情况明、决心大、方法对，缺一不下发决定 |
| 估计留余地 | 把困难估多、周期估长，并公开说明余量在哪 |
| 集中优势与放弃清单 | 同一时间只留一个主攻方向，造出相对优势，并写出主动放弃清单 |
| 一般号召与个别指导 | 先普遍部署，再抓两三个点突破，拿回经验修正部署 |
| 群众路线闭环 | 收集分散意见、加工成系统意见、回流成执行者自己的判断、在行动中检验 |
| 一个时期一个中心 | 一个时期只能有一个中心工作，其余排二三位，并给投入上限 |
| 会议与决策机制 | 会前发议题、会中摆到桌面、会后落到具名条款，常委会与全体会分开 |
| 报告制度 | 固定字段、固定周期、主责人署名、字数上限，第三段不许只报喜 |
| 三分法：发展进步、争取中间、孤立顽固 | 把场上所有人切成三段，配三种动作，并认清三者联动 |
| 有理、有利、有节 | 只在对方先动手时反击、只打有把握的一仗、达到目的即停 |
| 不要四面出击 | 数清敌对者，用一次具体让步换一方不反对，把力量集中到主要方向 |
| 统一战线中的独立自主 | 合作中可以共享目标与指挥，但思想、政治、组织三条不交出去 |
| 主要矛盾抓取 | 列矛盾不列任务，按影响力而非紧急度找出那一条，压资源上去 |
| 矛盾特殊性五层切分 | 从领域落到阶段逐层分析，结论能搬到别处就说明还没沉到底 |
| 分析三戒：主观性、片面性、表面性 | 用三把尺子给已做出的判断做反向体检，片面性必须靠对偶清单硬查 |
| 转化条件审计 | 把 A 变 B 的条件拆开三分类，造不出的必要条件即判定不成立 |
| 两类矛盾判别 | 先判是敌我还是是非，再决定用强制还是说服，并设性质漂移警报 |
| 双向变化审计 | 对双方各算向上与向下两笔账，标出量与质、一次性与持续性 |
| 全局—局部关照 | 先界定你的全局，再找失去即崩的关节，其余列入可弃清单 |
| 初战三原则 | 第一仗必须打赢、必须顾全战役、必须想到下一阶段，三条缺一就推迟 |
| 创造条件清单 | 把等时机换成六项可勾选的条件，至少造出两项再动手 |
| 层级反转：战略持久、战役速决 | 战略层认账长期，战役层要求快而狠，两层方针必须相反 |
| 因素时效分层 | 把优势劣势分成临时项与经常项，长期判断只看经常项 |
| 纸老虎两层 | 长期层藐视、当下层重视，两层同时成立才既敢开局又不挨咬 |
| 写清楚的三个硬要求 | 三段结构、禁绝空话、按内部联系分类，删掉序号逻辑仍要成立 |
| 思想斗争的操作规矩 | 惩前毖后、治病救人、讲证据、落到下次做法，不做人身攻击 |
| 落实的节奏：检查与蹲点 | 常规任务按季检查，未上轨道的按月检查，并固定时间下现场 |
| 信息失真的两头治理 | 上头对自报数字折价验真，下头让人敢讲真话，两头同时治 |
| 古今中外法 | 把对象同时放进时间轴与对手轴，找出哪一半能学、哪一半不能学 |
| 两侧夹逼：用两个反向偏差定性 | 同时问做过头与做不足会怎样，把正确位置夹在两端之间 |
| 参数化复制 | 把点上的经验拆成动作层条款，标出可变量，写成别人能照抄的东西 |
| 决定点法：收敛成两个抓手 | 在庞杂领域里找出两个高敏感支点，其余按常规处理 |
| 宣传的组织化 | 一把手定调、分层加料、懂政策的人终审、固定节奏出刊 |
| 口号阶梯与说服减法 | 把总目标拆成今天就能接受的一级，少讲道理多给现场 |
| 分发按渠道，姿态取“哀者” | 同一主张按接收端换形态，占理时不逞强，让中间派替你说话 |
| 三三制：主动压自己的份额 | 掌权方明文给自己的席位设上限，用让位换长期合作与真实信息 |
| 精简是保骨干 | 先定不能砍的骨干，再砍重叠与协调层，五项目标同查 |
| 政策成套执行 | 先画政策依赖图，逐条检讨执行率，允许暂缓但不许静默丢弃 |
| 纠偏机制：不泼冷水，设比例上限 | 纠错彻底但给人留路，同时给清查设上限防止用规模证明决心 |
| 公开—秘密双轨 | 明暗两套名单严格分开又能互相配合，并预设断点 |
| 基层优先 | 拿到新阵地后先建基层再建门面，干部不许堆在中心 |
| 先给后取 | 先交付对方最痛的一件事，再谈你的索取，长期算总账 |
| 民办公助：自愿入股，禁止摊派 | 产权决策在参与者手里，上级只给条件不给指挥权，禁止摊派 |
| 清算四段：讲—查—议—分 | 利益重分配必须走完讲清、核查、议定、执行四步 |
| 谈打两手 | 谈判不绑住行动，先算破裂责任，先打后拉不拉得过早 |
| 成分—利益—比例 | 从成分、利益方向、力量比例三步解释一次联盟破裂 |
| 围点打援 | 把攻击点降级为诱饵，主力放在援军必经路上 |
| 决战三分：该决的决、该避的避 | 该决的决、该避的避、绝不赌掉第二次机会 |
| 反包围：先数清自己怎么被围 | 数清围法，找协同最差的一路，在局部反包围 |
| 三级协同 | 战略目标、战役里程碑、执行接口三层齐备，缺中层则上层失效 |
| 开合节奏：打与整同一周期 | 把休整排进周期并锁死，不打到垮为止 |
| 外线远征六查 | 补给、群众、地形、敌情、回旋、内固六项体检，缺一不去 |
| 攻坚三前提 | 先断外援、再找内应、最后才碰硬壳 |
| 决心链：材料—判断—决心—部署 | 四段各有失真，先定位断在哪一段再修 |
| 三级枢纽 | 战略枢纽定战役、战役枢纽定战斗，三级一线贯通 |
| 位置审计 | 先算自己在对手动作弧内还是弧外，再定避险或布局 |
| 战场选择与粮道 | 先算补给能支撑到哪，再定在哪里打 |
| 军事民主与权限边界 | 方法可讨论、指挥权不下放，主官须对意见给理由 |
| 新式整军 | 在两次硬仗之间插入诉苦与三查，把认同落到具体经历 |
| 俘虏政策：分档与即俘即补 | 分层处置、快速吸纳技术兵、专人负责转化 |
| 入城三条线 | 一律保护、只处理抵抗者、不扩大打击面 |
| 军工自建与取给于敌 | 自建定上限、外取定速度，两条都要有 |
| 兵力结构：不抽空基层 | 抽调骨干先定基层最低配置，分批输送边抽边建 |
| 练兵热潮：官教兵、兵教官、兵教兵 | 标准动作 + 一线反哺教材 + 最强的人带组，三条轮转 |
| 根本好转的三个条件 | 把好转拆成指标与结构两件事，只认结构条件完成 |
| 两问题分层 | 先定决定性问题，再写最不利情况与其连带后果 |
| 有把握的数量门槛 | 把能不能干成折成倍数与数量对账，说不出倍数就是没把握 |
| 按对手质地定规格 | 对手变强时单次规格下调一个量级，靠次数累积 |
| 稳、准、狠三维自检 | 强力行动前查三项：策略是否稳、对象是否准、执行是否一次到位 |
| 三层清理：先外后内 | 按距核心远近分三层，外层批量、内核优先，要害不排队 |
| 加速不跳序 | 要快就压缩准备期，不跳过必经阶段 |
| 政策变更三前置 | 给三条理由、双向收集赞成与反对、定决策时限 |
| 政策解释回到限定条件 | 回原文找限定语，按条件重新分档，而不是重新表态 |
| 划界三问：对象、范围、比例 | 按性质而非身份定对象，写清范围，算受影响比例 |
| 宽严档次先写死 | 五个维度各取两档，先定档次表再处理个案 |
| 首例管理 | 头几批逐案上报以定尺度，标准形成后再放开 |
| 基层的乱先到上面找制造者 | 基层负担多半来自上级多头索取，治理方向在减少向上索取 |
| 叫停权与改令权分开 | 下级可请求推迟，但不可自行改动目标与标准 |
| 标准按多数人做得到写 | 以多数人的可行性定规范，少数人能做的降为倡导 |
| 改造路线图：形式清单+时间刻度 | 列出中间形态与入口条件，给出总时长与无震动指标 |
| 一竿子到底 | 中间层在过滤时，把政策原文直达末端并开回传口 |
| 会议配人：留一成反方席位 | 开会必须有思想不通的人在场，约一成，且要让他们先说 |
| 指标下达三戒 | 不摊派、只给区间、不许吹压许愿，让接收方按条件报数 |
| 权责对齐 | 谁组织生产谁管分配，决策权与后果承担并到同一层 |
| 规则可算性 | 数参数、测理解成本，算不清的规则等于没有规则 |
| 调查组十项自检 | 出发前讲政策态度方法、不追责、原始件不修饰 |
| 定性先落比例 | 把普遍严重换成十分之几，查证后再定处置力度 |
| 政策文本四校准 | 期限、比例、义务、例外四项齐备才定稿 |
| 文件生效四道 | 名单、时限、交换、转化四道齐备才算生效 |
| 先让执行者改稿 | 会前发草稿请人改，会上只讲补充不照念 |
| 让人讲话先公布免责线 | 写明免责范围与三不，并由主官先自我批评兑现 |
| 先认账，账按层级分领 | 最高层先认第一笔具体账，各级认自己那段，不搞连坐也不模糊 |
| 制度变更写明多少年不变 | 给出明确稳定年限，划清根本制度与可变办法，例外走试办 |
| 人不到位文件不下发 | 有能解释的人到位才发，先内后外，宁可晚发 |
| 方法改不动就设死线换主体 | 给明确死线并声明替代方案，让不改变的代价具体化 |
| 重大选择两禁：草率与拖沓 | 定义确有根据的标准与期限，两者先到即决策 |
| 减负给硬比例，被减方参与定案 | 定可验收的比例，由被减方讨论决定砍哪一项 |
| 两对适配：能力—制度—观念 | 用两组平衡判断错位：能力与制度、制度与共识，只修最早错位那组 |
| 计划多级编制 | 各级都是计划机关，上级汇总不代编，专业部门只给口径 |
| 平衡表滚动：年—季—月三层修 | 年定框架、季校偏差、月调执行，改计划是常态不是失败 |
| 并举清单：成对布置、每对定主导 | 把并列事项配成对，每对定主导方与配比，按配比分资源 |
| 商品与调拨的边界 | 看责任主体是否转移：转移则定价核算，不转移则配额调度 |
| 高积累的安全判定 | 增速与末端改善两条同时成立才叫可持续，缺一条就是透支 |
| 计酬主辅：用副作用测薪形式 | 列出候选激励形式，测各自会放大哪类矛盾，定主辅 |
| 身心训练：先诊四因，再守三则 | 四问定目的方法量，三则守有恒、注全力、蛮拙 |
| 问题与主义分两层 | 先用三句话立判断依据，再拆成10-30条可认领的清单 |
| 治学次序：先博后约 | 先铺面再收窄，本域先摸清再引外部参照，先通用再专门 |
| 札记三动作：积、条理、去渣 | 先攒、再按自己的问题重新归类、定期删掉不再重要的 |
| 从最小共同利益单元起联合 | 最小单元先成型有构造，再按利益范围逐级拼装 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
