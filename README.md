# 毛泽东著作方法论 · 能力卡技能包

把《毛泽东选集》《文集》《军事文选》《建国以来毛泽东文稿》等 41 册、约 **1,134 万字**读成 **113 张可执行的能力卡**：每张卡给出「原文原句 + 什么时候用 + 怎么做 + 什么时候会失效」。

目标不是复述思想，而是把散落在讲话、电报、批注里的**工作方法**抽出来，变成遇到具体局面时能照着走的东西。

---

## 它长什么样

每张卡六段式：

| 段 | 内容 |
|---|---|
| **R** 原文 | 逐字引文 + 出处，可回原书核验 |
| **I** 是什么 | 这套方法的输入、步骤、输出 |
| **A1** 实例 | 作者实际用过的一次 |
| **A2** 什么时候用 | 触发条件 / 不触发条件 |
| **E** 怎么做 | 可步骤化执行 |
| **B** 边界与失效 | 什么情况下会失灵、失效形态是什么 |

例（节选）：

> **高积累的安全判定**
> ——“这个问题要看生产增长的情况。如果生产增长得很快，在这个基础上，即使积累的比重大一些，人民生活还能够逐步改善，也可以是没有危险的。”
>
> 判断“投入比例是不是过高”，不看比例本身，看两个条件是否同时成立：① 增速条件——产出增长是否真的够快（不是计划增速，是实际增速）；② 末端条件——处于最末端的人，其状况是否仍在改善。两条同时成立，高投入可持续；缺一条，就是在透支。

## 怎么用

### WorkBuddy

把整个目录放到技能目录：

```
~/.workbuddy/skills/mao-fangfa-lun/
```

对话中直接问具体问题即可，例如：

- “七八件事都在催，资源不够，先做哪件？”
- “会开了没结果，下次还是和和气气怎么办？”
- “公司要砍 20% 编制，按什么顺序砍？”

### 其他 Agent 框架

`SKILL.md` 是带 YAML frontmatter 的 Markdown，正文是「触发条件 + 路由表 + 场景包」。多数支持 `SKILL.md` 约定的框架可直接读；不支持的，把 `SKILL.md` 当作系统提示、`references/` 当作可检索资料库亦可。

### 两种查法

- **知道自己卡在哪** → 查 `SKILL.md` 里的 113 行路由表（一句话意图 → 卡）
- **只知道面对什么局面** → 查 `references/index-scenes.md` 的 15 个场景包

场景包里的组合是「主卡 + 标配组合」。**第二张不是备选，是必需**——单用主卡最常见的失败是判断对了但落不下去。

## 质量声明（请按实际情况使用）

这是本仓库最该看清楚的一节。

**已核验的：**

- **引文 113/113 逐字可回原文**。构建期跑过全量审计（标点空白归一、省略号分段、每段必须在语料中命中）。首轮审计发现 31 张卡的引文是压缩或改写，已全部修正，其中 2 张降级标注为“本单元为归纳，非单句原文”。
- 卡片结构一致，六段齐全。
- 编译校验 0 错误。

**已知不足：**

- **路由准确率不是 100%**。实测 17 条用例：触发边界 15/15 正确（10 条该触发全触发、5 条不该触发全拒绝）；**主卡命中 9/10，但配套第二张只有 4/10**。也就是说，它常能选对主要方法，但容易漏掉配套的机制性那一张。
- 部分单元是归纳而非单句原文（已在卡内标注）。
- 二手材料（他人读书笔记、语录摘编）只用于校验，**未作为任何一张卡的引文来源**，因为二手转述无法回原文核验。

**结论**：可以当一份查得动的参照，别当判决书。每条卡都给了原文，遇到关键判断应该回去核原句。

## 它是怎么做的

七批增量处理，每批走同一条流水线：

1. **提取**：框架 / 原则 / 案例 / 反例 / 术语五类抽取器并行
2. **合并**：按「可迁移动作」合并同类，重复的并入已有卡
3. **建卡**：六段式结构，引文逐字回校
4. **审计**：`audit_quotes.py` 全量比对，未命中即打回
5. **编译**：生成 `SKILL.md` 路由表与 `references/`
6. **校验**：`validate_skill_pack.py`，0 错误才发布
7. **评测**：17 条用例实跑，按“是否激活 / 选哪张卡”评分

两个硬闸：引文审计、编译校验。任一不过不许发布。这条规矩是因为第一轮发现 29% 的引文不合格才立的。

## 不含什么

**本仓库不包含原书全文语料。** 抽取用的 41 册电子文本不在库内，一是体积（约 30MB），二是版权。仓库里只有蒸馏产物与逐字短引文。

**不适用于**：纯事实查询、纯技术计算、需要专业资格的判断（医疗/法律/工程安全/财务审计）、历史是非评价、情绪疏导。素材里的历史内容只作为方法论的载体，本仓库不对历史作评价。
